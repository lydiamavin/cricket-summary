# 🏏 Cricket Comic Strip Generator

AI-powered comic strip generator for cricket matches.  
This project transforms cricket match data into **visual comic strips** using multiple AI image generation APIs.

---

## ✨ Key Features

- **Interface**  
  🌐 **Streamlit Web App** – simple UI for input & output visualization.
 
- **Multiple AI Generators**  
  Supports OpenAI (DALL·E), Google Gemini, and xAI Grok for image generation.  

- **Configurable**  
  Uses `.env` file for API keys and generator selection (`GENERATOR=openai` / `gemini` / `grok`).  

- **Modular Architecture**  
  Generation logic is separated for easy extension with future AI models.
